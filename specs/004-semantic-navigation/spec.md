## User Scenarios & Testing

### User Story 1 - 遠近を切り替えて全体を読む (Priority: P1)

利用者はキャンバスを縮小すると、細部に埋もれず名前付きの囲みを全体のまとまりとして読める。拡大すると元の内容をそのまま確認できる。

**独立した検証**: 文字・囲み・図形・矢印・手書きのあるボードを拡大縮小し、近・中・遠で見える内容と保存済み座標を比べる。

**受け入れシナリオ**:

1. **前提** 本文を含むボード、**操作** 本文の画面上サイズを9以上、5以上9未満、5未満へ変える、**結果** 近・中・遠の表示に切り替わる。
2. **前提** 端末の文字サイズを変更した、**操作** 同じボードを表示する、**結果** 段階の境界が変更後の本文の見かけの大きさに追従する。
3. **前提** 名前付き囲みの表示幅が120未満または高さが90未満、**操作** 近・中で見る、**結果** その囲みだけまとまった遠景表示になる。
4. **前提** 遠景の名前付き囲み、**操作** 拡大する、**結果** 隠れていた要素は保存時の位置と内容で再表示される。

### User Story 2 - 見たい場所へすばやく移動する (Priority: P2)

利用者はズーム表示、空白のダブルタップ、まとまった囲みのタップから視点を移し、全体と細部を行き来できる。

**独立した検証**: 3つの操作を各段階で試し、移動先、視点の滑らかさ、ボード内容が変わらないことを確かめる。

**受け入れシナリオ**:

1. **前提** 近・中・遠のいずれか、**操作** 右下のズーム表示を押す、**結果** 近→中→遠→近の順に切り替わり、現在の倍率と段階が表示される。
2. **前提** 空白、**操作** ダブルタップする、**結果** 近なら中へ引き、中・遠ならタップ地点を中心に100%へ寄る。
3. **前提** 遠景または小さくまとまった囲み、**操作** 囲みをタップする、**結果** 囲み全体が見える位置と倍率へ移動する。

### User Story 3 - 言葉から要素を探す (Priority: P3)

利用者は文字の内容または囲みの名前でボード内を検索し、件数と現在位置を見ながら該当箇所を巡れる。

**独立した検証**: 複数の文字・囲み、0件、大小文字違いを検索し、件数、順序、視点移動、終了後の表示を確かめる。

**受け入れシナリオ**:

1. **前提** ボード表示中、**操作** 右上の検索を開く、**結果** 入力欄にフォーカスが移り、文字と囲み名を入力できる。
2. **前提** 複数の一致、**操作** 入力または前後移動する、**結果** 一致数と現在位置が表示され、現在の一致へ視点が移る。
3. **前提** 検索中、**操作** パン・ズームまたは検索終了、**結果** 検索中も視点を操作でき、終了すると通常表示に戻る。

### Edge Cases

- 段階の境界値は上位の段階に属する。倍率の上限・下限で指定の見かけサイズを達成できない場合は、許容倍率内の最も近い値を使う。
- 選択中の要素と検索一致は、通常なら隠れる位置や種類でも表示する。表示されない要素は偶然タップしても選択されない。
- 入れ子の名前付き囲みでは、外側がまとまったら内側の囲みと内容を隠す。検索一致と選択中の対象は例外として見える。
- 検索語が空または一致が0件のとき、件数表示と前後移動を矛盾なく扱い、視点を勝手に動かさない。
- 長い見出しは隣の囲みや図形と重ならないよう省略し、2文字も表示できなければ隠す。
- 表示段階の変更、検索、視点移動は Undo/Redo の対象にせず、保存データを変更しない。

## Requirements

### Functional Requirements

- **FR-001**: 本文の画面上の見かけサイズにより、9以上を近、5以上9未満を中、5未満を遠と判定する。端末の文字サイズ設定を反映する。
- **FR-002**: 近では全要素を表示し、本文は画面上10、見出しは11を下回らない読みやすさに補う。
- **FR-003**: 中では見出しを11以上の1行に、本文を薄い1行に簡略化する。遠へ近づくにつれ本文と矢印を薄くし、囲みの名前を強調する。
- **FR-004**: 遠ではすべての囲みを淡い面で表し、名前がある場合は中央へ示す。名前付き囲みの中身と通常の本文を隠す。囲み外の見出しは薄く小さく残す。
- **FR-005**: 名前付き囲みの見かけの幅が120未満または高さが90未満なら、その囲みだけ遠景の表現にする。まとまった外側の囲みに含まれる内側の囲みも隠す。
- **FR-006**: 隠れた要素に接続する矢印、中心が内部にある文字が1つ以上あり、その文字がすべて隠れた図形を隠す。文字を含まない図形はこの条件だけでは隠さない。遠では画面上20未満の矢印、24未満の図形、16未満の手書きも隠す。
- **FR-007**: 中・遠の見出しは囲みの右端または右隣の囲み・図形の手前で省略する。2文字も残せない場合は隠す。
- **FR-008**: 選択要素と検索一致を常に可視に保ち、隠れた要素をタップやアクセシビリティ操作の対象にしない。
- **FR-009**: 右下の倍率表示から近→中→遠→近を巡れる。中の目標は本文の見かけ7、遠は3.5、近は100%とし、許容倍率内に収める。
- **FR-010**: 空白のダブルタップは近から中へ、中・遠からタップ地点を中心とする100%へ移動する。まとまった囲みのタップは囲み全体へフィットする。
- **FR-011**: 段階切替、ダブルタップ、囲みフィット、検索結果への視点移動は約0.34秒で滑らかに行う。利用者による直接パン・ズームはその操作に追従する。
- **FR-012**: 検索対象は文字の内容と囲み名とし、大文字小文字を区別しない。結果は要素の上端、同じ高さでは左端の順に安定して並べる。
- **FR-013**: 検索欄を開いたら入力にフォーカスする。入力のたびに先頭の一致へ移動し、前後の操作と Enter で末尾から先頭にも巡る。現在位置と総件数、0件では「0件」を表示する。
- **FR-014**: 一致を淡い朱、現在の一致を濃い朱で示し、その他の要素を薄くする。検索中もパン・ズームでき、検索終了で通常表示に戻る。
- **FR-015**: 表示の簡略化、検索、視点操作によって、要素の内容、座標、関係、保存データ、Undo/Redo 履歴を変更しない。
- **FR-016**: 倍率表示、検索欄、前後移動、閉じる操作を支援技術から識別・実行できるようにし、現在の検索件数を読み上げられるようにする。

### Key Entities

- **表示段階**: 本文の見かけサイズから求める近・中・遠。保存するボード要素ではない。
- **表示状態**: 各要素の可視性、薄さ、省略、まとまった囲みの状態。現在の視点と文字サイズに応じて変わる。
- **検索結果**: 検索語、一致要素の順序、現在の一致。ボード要素の内容と配置は保持する。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 3種類以上の端末文字サイズ設定と境界値を含む倍率で、近・中・遠の判定が全ケースで期待どおりになる。
- **SC-002**: 名前付き囲みの大小と入れ子、選択・検索一致を含むボードで、非表示要素への誤選択が0件になる。
- **SC-003**: ズーム表示、空白ダブルタップ、囲みフィットで指定先へ約0.34秒で移動し、操作後も全要素の保存座標が一致する。
- **SC-004**: 0件・1件・複数件の検索で、件数、前後の順序、現在の強調、視点移動が全ケースで一致する。
- **SC-005**: 表示、検索、視点操作の前後でボードの内容と Undo/Redo 履歴が一致する。

## Assumptions

- PRD の画面上の `px` は Android では見かけの表示単位として扱い、端末の密度と文字サイズ設定を踏まえて比較する。密度の異なる端末で同じ視覚上の段階となることを優先する。
- 対象は端末内の現在のボードのみ。OCR、AI検索、外部検索、検索結果の分類や並べ替え、要素の自動配置は含めない。
- 非公開 PRD を要件の根拠とし、HTML モックを画面配置・操作感の参考にする。両者の差は PRD を優先する。
- 実機での表示の見え方は、エミュレーター確認の後に他の Issue とまとめて確認する。

## Clarifications

### 2026-09-27

- PRD の9・5という境界は、それぞれ近・中側を含む。Android の表示密度で物理 pixel 数が変わっても視覚上同じ段階となるよう、画面上の見かけの単位に換算して扱う。
- 図形内に文字がない場合、「中の文字がすべて隠れた」とは扱わない。囲みのまとまりと遠景の小ささによる規則は別途適用する。
- 検索一致がまとまった囲みの内側にある場合、一致要素を例外として表示し、その位置へ移動する。検索終了時は通常の段階表示へ戻す。
- 検索結果は画面位置ではなく要素の保存位置に基づいて並べ、同じ位置では識別子で順序を安定させる。
