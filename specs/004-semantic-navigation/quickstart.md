# 検証手順: Semantic Navigation

## 事前条件

Android 17 エミュレーターまたは対応端末で、文字、見出し、名前付きの大小・入れ子の囲み、図形、矢印、手書きを含むボードを用意する。詳細な期待動作は [操作契約](contracts/interaction.md) に従う。

## 自動確認

```powershell
.\gradlew.bat :app:lintDebug :app:testDebugUnitTest :app:assembleDebug :app:connectedDebugAndroidTest
pwsh -File scripts/check-public-boundary.ps1
git diff --check
```

## 画面確認

1. 端末の文字サイズを標準・小・大に変え、同じ倍率で近・中・遠の境界が本文の見かけに追従することを確認する。
2. 名前付き囲みを縮小し、単独でまとまる閾値、外側の囲みがまとまったときの入れ子、図形・矢印・手書きの非表示条件を確認する。
3. 隠れた要素をタップしても選択されず、選択中や検索一致の要素は見えることを確認する。
4. 倍率表示、空白ダブルタップ、まとまった囲みのタップを試し、目標視点と滑らかな移動を確認する。
5. 複数件、1件、0件、大小文字違いの検索を試し、件数・前後・IME検索・強調・検索中のパンとズームを確認する。
6. 検索と視点移動の前後で要素の内容・配置・Undo/Redo履歴が変わらず、再起動後も元のボードが残ることを確認する。
7. TalkBack で倍率表示と検索を操作し、非表示要素が読み上げ対象にならないことを確認する。

実機の視覚的な仕上がりは、利用者の方針に従って後日まとめて確認する。
