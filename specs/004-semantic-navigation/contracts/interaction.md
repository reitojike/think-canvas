# 操作契約: Semantic Navigation

## 表示

- 本文の見かけの大きさを基準に近・中・遠を決める。境界値9は近、5は中に含む。
- 名前付き囲みの見かけ幅120未満または高さ90未満は局所的にまとめる。外側がまとまれば内側は隠す。
- 選択中と検索一致は常に表示し、非表示要素は描画・タップ・TalkBack の対象から外す。
- 段階を戻したとき、保存された内容と世界座標がそのまま見える。

## 視点移動

- 倍率表示は現在の `%` と近・中・遠を表示し、押すたびに近→中→遠→近を巡る。
- 中の目標は本文の見かけ7、遠は3.5、近は100%。許容倍率で達しない場合は境界値で止まる。
- 空白のダブルタップは近から中、中・遠からタップ地点を中心とする100%へ移る。まとまった囲みのタップは囲み全体を表示領域内へ収める。
- 自動移動は約340ms。利用者のパン・ピンチが始まれば中断して直接操作へ移る。

## 検索

- 右上で検索を開くと、単一行の入力欄へフォーカスする。
- 対象は文字の内容と名前付き囲みの名前。大文字小文字を区別しない。
- 入力変更時は先頭一致へ移動する。前・次・IMEの検索操作で循環する。結果は「現在 / 総数」、0件なら「0件」。
- 一致は淡い朱、現在位置は濃い朱、それ以外は薄くする。検索中もパン・ズームできる。閉じると通常表示へ戻る。
- 検索、表示、視点操作は保存データと Undo/Redo 履歴を変更しない。
