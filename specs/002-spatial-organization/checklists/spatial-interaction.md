# 要件レビュー用チェック: Spatial Organization

**対象**: [仕様](../spec.md)・[計画](../plan.md)
**用途**: PR レビューで空間操作、保存、アクセシビリティの要求の質を確認する。各項目の判定は reviewer が行う。

## 要素と関係

- [ ] CHK001 四角・丸・囲みの違い、作成方法、既定値、最小値は一意に読み取れるか。[完全性, FR-002/003]
- [ ] CHK002 囲みの中心判定と入れ子・重なりでの重複除去は、保存値に依存する形で定義されているか。[明確さ, FR-005]
- [ ] CHK003 矢印の接続端と自由端について、移動・サイズ変更・削除時の扱いが矛盾しないか。[整合性, FR-006/007/020]
- [ ] CHK004 矢印の曲げと反転について、見た目と保存状態の期待結果が明示されているか。[明確さ, FR-008]

## Gesture と余白

- [ ] CHK005 #2 のパン・ズーム・文字編集と #3 のツール・長押し・つまみの優先順位は明確か。[整合性, FR-001/017]
- [ ] CHK006 囲み選択の対象条件と、追加・解除・選択数の遷移は検証可能か。[網羅性, FR-009]
- [ ] CHK007 余白の軸、押し出し側、伸ばす要素、最小囲みの作用範囲は一意に判断できるか。[明確さ, FR-010/011]
- [ ] CHK008 中断・二本指への遷移・保存失敗で未確定 preview を残さない条件はあるか。[境界条件, FR-012/019]

## 保持と利用しやすさ

- [ ] CHK009 v1 の文字とボードを失わず、新要素を保存・再起動後に復元する条件があるか。[網羅性, FR-019]
- [ ] CHK010 複数要素を含む一操作の Undo/Redo と、接続先削除時の矢印の扱いは揃っているか。[整合性, FR-012/020]
- [ ] CHK011 視覚・振動・支援技術・タッチ以外の経路の要求が、すべての主要操作に届くか。[網羅性, FR-013/014/018]
- [ ] CHK012 HTML モックに合わせる対象と、PRD を優先する境界が明確か。[追跡可能性, FR-016]

## 注記

`[x]` は reviewer が要件の記述品質を確認した印であり、実装完了を意味しない。未判定のままでも `requirements.md` の仕様品質判定とは区別する。
