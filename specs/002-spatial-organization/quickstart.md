# 検証手順: Spatial Organization

## 準備と自動チェック

README に記載された JDK と Android SDK を用意し、Android の実機またはエミュレーターを起動する。既存の v1 データを保持した端末も、移行検証に使う。

```powershell
.\gradlew.bat :app:lintDebug
.\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:assembleDebug
pwsh -File scripts/check-public-boundary.ps1
git diff --check
```

GitHub CI でも、現在の PR head に対して同じ四種類のチェックを確認する。

## 操作確認

1. 文字を二つ置き、右下の＋から四角・丸・囲みをそれぞれ tap と drag で作る。囲みの名前を空と日本語の両方で確定し、右下つまみでサイズ変更する。形の内側の空白からパンできることを確認する。
2. 囲みの内側へ文字と別の囲みを置き、外側の囲みを動かす。中身が同じ差分で一度だけ動くことと、サイズ変更では中身が動かないことを確認する。重なる囲みでも繰り返し、要素が囲みに入る/出るときの案内を確認する。
3. 矢印を文字と図形へ接続し、一方を外して自由端にする。接続先を移動・サイズ変更し、接続端だけが追従することを確認する。曲げと向きの反転を行う。
4. 「まとめて選ぶ」で文字・図形・囲み・矢印を囲み、追加と解除で選択数を確かめる。まとめて移動し、一度の Undo/Redo で前後に戻ることを確認する。
5. ボードの空白から横と縦の余白を作る。境をまたぐ図形・囲みが伸び、押し出し対象だけが動くことを確認する。入れ子の囲み内からも試し、外の要素が動かないことを確認する。
6. 作成・移動・サイズ変更・接続変更・余白・削除を Undo/Redo する。gesture を途中で取り消し、preview が保存されないことを確認する。
7. ネットワークを切ってアプリを完全終了・再起動し、文字、図形、囲み、矢印の位置・名前・色・接続を確認する。既存 v1 のボードと文字も失われていないことを確認する。
8. HTML モックと、＋メニュー、選択枠、操作つまみ、矢印の端点、余白の帯、上部案内、長押しメニューの通常・操作中状態を照合する。
9. TalkBack と文字サイズ変更で各要素の種類・名前・選択数を確認し、タッチ gesture 以外で主要操作へ到達する。新しい操作つまみのタッチ領域を確認する。

操作の期待結果は [interaction.md](contracts/interaction.md)、保存と不変条件は [data-model.md](data-model.md) を参照する。PRD と HTML モックの元ファイルはリポジトリに追加しない。
