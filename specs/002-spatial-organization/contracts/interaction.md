# 画面操作の契約: Spatial Organization

## 入力の優先順位

1. ツール、メニュー、入力欄などの画面 UI はキャンバスより優先する。
2. 選択中のサイズ変更つまみ、矢印の端点・曲げつまみ、移動つまみを判定する。
3. 文字、図形・囲みの線近傍、矢印の線近傍を判定する。図形の内側の空白は通常のキャンバス操作に渡す。
4. 空白では、開始点が囲みの内側かを別に記録する。通常 tap は文字入力、長押し drag は余白挿入になる。

指が二本になったら未確定の単一指操作を破棄し、#2 のパン・ズームへ移る。cancel と操作対象を失った場合も preview を破棄する。正常な release のみ確定して保存する。

## 操作ごとの結果

| 状態と操作 | 結果 |
|---|---|
| ＋から四角・丸・囲みを選び tap | 試作の既定サイズで作り、囲みは名前入力に入る |
| 同じツールで drag | 始点と終点から大きさを決め、release で一つの要素を作る |
| ＋から矢印を選び drag | 始点・終点の下の要素へ接続し、空白側は自由端にする |
| ＋から「まとめて選ぶ」を選び囲む | 中心が内側の要素、両端が内側の矢印を選ぶ |
| 要素の tap | 選択する。選択中の囲みの再 tap は名前編集に入る |
| 複数選択中に選択済み要素を tap | その要素を選択から外し、数を更新する |
| 別の要素を長押し | 現在の選択に追加し、数を更新する |
| 要素を長押しして drag | 対象の移動 preview を示し、release で一操作として確定する |
| 要素を長押しして release | 対象に合う操作メニューを開く |
| 四角・丸・囲みの右下つまみを drag | 位置を保ってサイズだけ変え、内側の要素を動かさない |
| 矢印の端点を drag | release 位置の要素に接続・付け替え、空白なら自由端にする |
| 矢印の中間つまみを drag | 曲がりを変更し、中央近くに戻すと直線にする |
| 空白を長押しして drag | 方向を決めて余白を preview し、release で一操作として確定する |

作成・移動・サイズ変更・接続変更・曲がり・余白・削除は Undo/Redo の対象。選択、パン、ズーム、メニューの開閉は対象外。

## 表示と支援技術

- 右下の墨色の＋と白い丸いツール、上部の墨色の案内、朱の破線選択枠、操作中の実線、矢印の接続端/自由端、余白の斜線帯を HTML モックの対象画面に合わせる。
- 長押し成立と操作成功の振動は [操作の意味に合わせたハプティクス](../../014-semantic-haptics/contracts/feedback.md) に従う。囲み出入りと余白方向の表示は維持する。
- ツールとメニューは標準のボタン操作で使える。描画要素ごとに種類・名前・選択状態を読み上げ、移動・サイズ変更・接続・反転・削除に gesture 以外の操作を提供する。新しいつまみは 48dp 以上のタッチ領域を持つ。
- ツールのアクセシビリティ操作から、表示中央への四角・丸・囲み・矢印の作成と表示範囲のまとめて選択を完了できる。作成後の要素は個別の操作で移動・サイズ変更・接続を調整できる。
- 矢印の始点・終点はアクセシビリティ操作から接続先と接続する側を選んで接続・付け替えられる。自由端への変更も別の操作で行える。
- 保存失敗時は未保存を明示し、同じ確定状態を再試行する。失敗中に次の変更を確定しない。
