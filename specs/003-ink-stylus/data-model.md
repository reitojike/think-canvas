# データモデル: Ink & Stylus

## 線のまとまり

`InkElement` は識別子、線種、複数の `InkStroke` を持つ。線種は `PEN` または `MARKER`。同じ線種で直前の線から1.5秒以内の描画だけが同じまとまりに追加される。選択・移動・削除はまとまり単位、追加の履歴は線単位。

## 線

`InkStroke` は識別子、終了時刻、入力点列を持つ。点は世界座標と描画開始からの経過時間を持つ。入力時に screen→world を行い、保存後の viewport 変更で座標を更新しない。線の移動では各点を同じ世界座標差分だけ動かす。

## 永続化

既存 schema v1 に ink の行を追加する。各行はまとまり ID、線の順番、線種、終了時刻、Ink の符号化入力を保持する。v1→v2 migration は新規テーブルのみ作成し、既存4テーブルと `thinkcanvas.db` の名前を維持する。保存は他の要素と同じ transaction で更新する。
