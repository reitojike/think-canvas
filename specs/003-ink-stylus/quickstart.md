# 検証手順: Ink & Stylus

1. `:app:lintDebug`、`:app:testDebugUnitTest`、`:app:assembleDebug`、`:app:connectedDebugAndroidTest`、公開情報境界チェックを実行する。CI でも Android 17 エミュレーターの操作テストを実行する。
2. エミュレーターでペンモードの指相当入力、マーカー、2点入力の移動・拡大縮小、グループ選択、Undo/Redo、再起動を確認する。自動テストでは指1本・指2本・スタイラス相当入力を各10回反復する。
3. 既存の文字、図形、矢印を持つ v1 DB から起動し、移行後の内容と位置を確認する。
4. 実機確認時には、スタイラス優先、ペンの追従、短い触覚フィードバック、指2本への途中切替を確認する。

実機確認はエミュレーター検証とは区別して PR と Issue に記録する。
