## User Scenarios & Testing

### User Story 1 - 指またはスタイラスで書く (Priority: P1)

利用者はペンモードで指を使い黒い細線を描ける。スタイラスなら現在のモードに関係なくペンで描ける。ペンモード中も2本指ではキャンバスを移動・拡大縮小できる。

**独立した検証**: ペンモードで指1本の線、2本指の移動・拡大縮小、通常モードでスタイラスの線を作り、意図しない線が残らないことを確かめる。

**受け入れシナリオ**:

1. **前提** ペンモード、**操作** 指1本でなぞる、**結果** 細い黒線が表示される。
2. **前提** 任意のモード、**操作** スタイラスでなぞる、**結果** ペンの線が表示され、指の通常操作はそのモードに従う。
3. **前提** ペンまたはマーカーモード、**操作** 2本指で移動・ピンチする、**結果** viewport だけが変わり線は追加されない。
4. **前提** マーカーモード、**操作** 指でなぞる、**結果** 文字の背後に見える太い半透明の朱色の線ができる。

### User Story 2 - 線を編集する (Priority: P2)

同じ種類の線を続けて書くと、選択・移動・削除では一つのまとまりとして扱える。Undo/Redo は線1本ごとに働く。

**独立した検証**: 1.5秒以内の同種の線、異種の線、時間が空いた線を作り、選択、移動、削除、Undo/Redo を確認する。

**受け入れシナリオ**:

1. **前提** 同種の線を続けて描いた、**操作** 前の線の終了から1.5秒以内に次の線を描き始める、**結果** 一つの選択対象となり短い触覚フィードバックがある。
2. **前提** まとまった2本の線、**操作** Undo、**結果** 後から描いた1本だけが消える。Redo で同じまとまりに戻る。
3. **前提** 線のまとまりを選択した、**操作** 移動または削除、**結果** 全ての線が一緒に変わり、他の要素の配置は変わらない。

### User Story 3 - 保存して再開する (Priority: P3)

線を描いた後にアプリを終了・再起動しても、線の形状、種類、位置、まとまりが残る。

**独立した検証**: 線を作成し、viewport を変更して再起動し、既存の文字・図形・矢印とともに表示と選択を確認する。

**受け入れシナリオ**:

1. **前提** 線と既存要素を保存した、**操作** アプリを再起動する、**結果** 線の形状・種類・世界座標、既存要素の内容と配置が維持される。

### Edge Cases

- 指の描画中に2本目の指が触れた場合、未確定の線を取り消し、2本指操作に切り替える。
- キャンセル、保存失敗、極端に短い入力で空の線や壊れた線を残さない。保存失敗は再試行できる。
- スタイラスと指が同時に触れた場合、スタイラスの線を優先し、指の位置を線に混ぜない。
- Undo 後の新規描画は既存の Redo 履歴を破棄する。
- 線のないボードと既存データベースを開ける。

## Requirements

### Functional Requirements

- **FR-001**: ペンとマーカーを切り替え、やめる操作で通常のキャンバス操作に戻れる。
- **FR-002**: ペンは細い黒線、マーカーは文字より背後に表示する太い半透明の朱色の線とする。
- **FR-003**: ペン・マーカーモード中の指1本は描画、指2本は移動・拡大縮小とする。スタイラスはモードに関係なくペンで描画する。
- **FR-004**: 線は viewport に依存しない世界座標に確定し、pan/zoom や再起動で形状・位置を変えない。
- **FR-005**: 同種の線を直前の線の終了から1.5秒以内に描き始めた場合、選択・移動・削除の単位を共有する。異種または時間外の線は別のまとまりとする。
- **FR-006**: 新しい線の追加は1本ごとの Undo/Redo 単位とする。まとまりの移動・削除は各操作を一つの Undo/Redo 単位とする。
- **FR-007**: 線のまとまりはタップ、長押し、範囲選択、アクセシビリティ操作で既存要素と同様に選択・移動・削除できる。
- **FR-008**: 線の保存と読み込みは端末内で完結し、既存のボード、文字、図形、矢印を失わない。
- **FR-009**: 描画中に指2本へ変わった場合、未確定の線を取り消して viewport 操作へ移る。

### Key Entities

- **線**: 種類、世界座標の入力列、描画時刻を持つ一回の連続した入力。
- **線のまとまり**: 同種で時間的に連続する線の集合。選択・移動・削除の単位。
- **描画モード**: 通常、ペン、マーカー。スタイラスはモードより優先する。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 指1本とスタイラスの描画、指2本の移動・拡大縮小を所定の手順で各10回行い、誤った線の確定が0回。
- **SC-002**: 同種の連続線、種類違い、1.5秒を超える線について、選択単位が全ケースで期待通り。
- **SC-003**: 3種類以上の viewport 位置・倍率で線を保存し、再起動後の世界座標と種類が全件一致。
- **SC-004**: 線の追加、まとまりの移動・削除、Undo/Redo 後も既存要素の位置と内容が変化しない。

## Assumptions

- ペンとマーカーは固定の2種類とし、太さ・色の編集、筆圧表現、消しゴム、OCR、図形補正、レイヤーは対象外。
- モックの見た目と配置を参照する。PRD と異なる箇所では PRD を優先する。
- 実機のスタイラス入力と触覚フィードバックは端末で後日まとめて確認する。エミュレーターでは入力分岐、描画、保存、操作を先行確認する。

## Clarifications

### 2026-09-27

- PRD の1.5秒は直前の同種の線の終了から次の線の開始までと解釈する。まとまりに追加された場合も Undo は線1本ずつ戻す。
- 指描画中の2本指化は線を確定しない。誤入力防止を優先する。
- 現段階の線の並び順はまとまり内で追加順とする。マーカーは文字の下、ペンは文字と他の図形の上に描く。
