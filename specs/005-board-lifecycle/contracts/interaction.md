# 操作契約: Board Lifecycle

## ボード一覧

| 操作 | 観測できる結果 |
| --- | --- |
| ボード名の左上から一覧へ戻る | 現在の編集が保存済みなら一覧が開く。編集中または保存中ならその操作を完了するまで移動しない。保存失敗なら再試行できる状態を保つ。 |
| 一覧カードをタップ | 対象ボードを開き、内容全体が収まる視点へ移る。最後に開いたボードを更新する。 |
| 一覧右下の＋ | 他ボードを変更せず、空のボードを作って開く。 |
| 一覧カードを長押し | 対象名を示す下部メニューを開く。名前を変える、複製、画像で共有、削除、キャンセルを選べる。 |
| 名前を変える | 入力した名前を対象へ保存する。空なら「無題のボード」と表示する。 |
| 複製 | 内容と配置が等しい独立したボードを作る。元を編集しても複製は変わらず、その逆も同じ。 |
| 削除 | 確認後に対象だけを削除する。確認を取り消すと何も変わらない。最後の1件も削除でき、一覧は空状態になる。 |

一覧は2列で、最近編集した順に遠景プレビュー、名前、日付を示す。画面下部に長押し操作の案内を置く。カードと各操作には支援技術向けの名前と役割を付ける。

## 初回案内

最初の空ボードを開いたときだけ下部に「基本の操作」を示す。「はじめる」で閉じると次回は自動表示しない。一覧右上の「使い方」から、同じ案内を任意の時点で再表示できる。案内中の操作は意図しないキャンバス編集を起こさない。

## 画像共有

ボード一覧のメニューではボード全体、キャンバス上の選択メニューでは選んだ部分を対象にする。共有シートは「画像で共有」、対象名、出力と同じ内容のプレビュー、「画像を保存」「コピー」「ほかのアプリ」を示す。空の対象なら出力せず理由を表示する。

画像は本文、見出し、図形、囲み、矢印、手書きを含み、位置と色を保つ。選択した名前付き囲みの内側に中心がある文字・図形・手書きを含め、矢印は明示的に選ばれたもの、または両端と接続先が囲みの内側にあるものだけを含める。背景は不透明な `#FCFCFB`、対象の外側には上下左右に同じ `max(24, 対象長辺×0.05)` 世界座標単位の余白を付ける。画像化で1 px/世界座標単位を下回る対象は出力せず理由を示す。一覧カードの遠景プレビューでは要素が省略されても、共有画像では省略しない。操作 UI、検索強調、選択ハンドルを画像へ含めない。

「画像を保存」を選んだ場合、Android 10 以降は端末の写真領域へ保存する。Android 8・9 は文書作成画面で利用者が保存先を選ぶ。コピーは画像 URI を持つクリップボード、ほかのアプリは Android 共有メニューへ渡す。保存先選択・共有メニューのキャンセル時は結果を知らせ、元データと履歴を変えない。
