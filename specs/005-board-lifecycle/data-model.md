# データモデル: Board Lifecycle

## ボード

既存の `boards` 行は `id: Long`、`name: String`、`updatedAt: Long` を持つ。`id` は現存するボード間で一意とする。名前の空文字は保存できるが、画面では「無題のボード」と表示する。`updatedAt` は内容の保存、名前変更、複製の作成で更新し、単に開く・プレビューする・共有する操作では変えない。同時刻の一覧順は `id` の降順とする。

新規作成には既存の最大 ID より大きい ID を同一の保存順序列内で割り当てる。削除後も残存 ID と衝突しないことを確認する。既存の単一ボード `id=1` とその要素はそのまま使用する。

## ボード要素

`text_elements`、`spatial_elements`、`arrow_elements`、`ink_strokes` の各行は既存の `boardId` を持つ。読込・置換・削除のすべてに対象 ID を指定し、他ボードの行へ触れない。矢印の接続先は同じボード内の文字または図形だけを許す。

複製では元の世界座標、色、本文、形、線、矢印の向きと接続関係を維持する。ボードと全要素の ID を新しくし、接続先 ID は複製側へ置き換える。画像共有は新しいボード要素を作らない。

## 利用状態

`lastOpenedBoardId` は最後に開いたボードを指す。指す先が削除済みなら破棄し、一覧を表示する。`guideDismissed` は案内の「はじめる」を押した記録で、ボードの追加や切替では戻さない。初回起動判定は0件状態と区別し、最後のボードを削除後の再起動で空ボードを自動再作成しない。

## 画面状態

画面は読み込み中、一覧、編集中のボードを区別する。編集中の状態は `boardId` と `BoardState` を一緒に保持し、保存 callback はその組の ID を固定する。保存完了前の切替・削除を防ぐ。開いたボードごとに Undo/Redo 履歴を作り、削除済みボードの履歴をほかへ移さない。

## 共有対象と描画計画

共有対象は `boardId`、固定した `BoardSnapshot`、対象 ID 集合、全体/選択範囲の種別からなる。選択した囲みの中身を対象へ加える。矢印の自動追加は、両端が囲み内にあり、接続先も対象に含まれる場合に限る。対象要素の外接範囲から均等な余白を追加し、縦横比を保って長辺4096 px・総画素16 MP以下の PNG サイズを計算する。非有限の座標と空対象は拒否する。

一覧のプレビューは現在の snapshot から作る遠景投影である。共有シートのプレビューは出力画像と同じ対象と描画計画を縮小したものである。これらは永続化されない。
