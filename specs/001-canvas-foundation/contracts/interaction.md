# 画面操作の契約

| 状態と操作 | 結果 |
|---|---|
| 未選択で空白 tap | その位置の新規 Draft を開く |
| 選択中に空白 tap | 選択を解除するだけ |
| 未選択の要素 tap | 要素を選択する |
| 選択済みの要素 tap | 編集 Draft を開く |
| 1 指 drag、長押し前 | 要素起点でも viewport をパンする |
| 要素上の長押し後 drag | 要素を移動する |
| 2 指 pinch | 15～300% の範囲で中心を基準に zoom する |
| 新規 Draft の空白確定 | 要素を作成しない |
| Draft の取消 | 既存の確定状態を維持する |
| Undo / Redo | 作成・編集・移動の前後状態を保存して反映する |

ボタンは名称と有効/無効状態を accessibility semantics に公開する。要素は内容と選択状態を公開し、タップ操作を touch gesture 以外からも実行できる。
